分类规划

面向未来持续扩展的目录结构。

📁

players/<slug>/

每位球员一个独立站点：index.html · css/ · js/ · data/ · assets/img/ · scripts/update_news.py。互不干扰，可单独部署。

🧩

shared/

跨球员复用的资源：vendor/(GSAP/ScrollTrigger) · css/hub.css · js/hub.js。换肤只需改各自 css/style.css 的配色变量。

🔄

每日自动更新

每位球员用各自的 update_news.py 抓取新闻，再由根目录 scripts/sync_news.py <slug> 增量推送到 GitHub Pages。

➕

如何新增

复制 players/stephen-curry/ 为 players/<新slug>/，替换 js/data.js 数据与 assets/img/ 图片，并在本页 LEGENDS 数组追加一项即可。
